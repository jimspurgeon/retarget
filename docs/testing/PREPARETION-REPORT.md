## Environment Sanity Verification

### 1. Notification Permission State

**Status:** ✅ Opt-in required (Android 13+)

**Evidence:**
```kotlin
// NotificationChannel.kt:72-97
fun checkPermission(): Boolean {
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
        val granted = ActivityCompat.checkSelfPermission(...) == PackageManager.PERMISSION_GRANTED
        if (!granted) {
            Log.w(TAG, "POST_NOTIFICATIONS permission denied; cannot deliver nudge")
            return false
        }
    }
    return true
}
```

**Manifest declaration:**
```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

**Behavior:** Users must explicitly grant permission; not auto-granted on install.

### 2. Quiet Hours Enforcement

**Status:** ✅ Enforced at multiple layers

**Default settings:**
- Start hour: 22 (10 PM)
- End hour: 7 (7 AM)

**Evidence:**
```kotlin
// BudgetPolicy.kt:17-18
```

**Enforcement layers:**

## Known Limitations (Documented for Testers)

### Functional Limitations

1. **WorkManager Drift:** Under Doze mode, scheduled notifications may arrive ±30–45 minutes off schedule
   - Mitigation: Disable battery optimization for test
   - Status: Accepted for MVP

2. **Single Notification Channel:** All goals share one system channel
   - Rationale: Reduces user confusion vs. per-goal channels
   - Status: Design decision (per PHASE2-CAMPAIGN.md)

3. **Round-Robin Copy Selection:** No fatigue-weighted copy variation yet
   - Future enhancement: Fatigue-weighted selection
   - Status: Logged for post-MVP

4. **APK Size:** 85MB due to bundled creative assets
   - Production path: On-demand asset loading
   - Status: Acceptable for testing only

### Bug Workarounds

| Issue | Workaround | Status |
|-------|------------|--------|
| Notification not dismissing on snooze | Manually swipe dismiss | Known bug |
| Pacing count lags refresh | Pull-to-refresh dashboard | Known bug |
